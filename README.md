# Artemis Resource Navigator
**Repository:** `Intellicore` | **Developed by:** Team Intellicore

An interactive decision-support platform designed for lunar exploration and base planning under NASA’s Artemis program. It combines archived NASA orbital datasets, a customizable Mining Viability Index (MVI), constraint-based rover route optimization, and a real-time 3D mission simulation into one complete workflow.

---

## 📱 Download & Install (Android APK)

You can download and install the pre-built Android application directly from the root directory of this repository.

### 1. Download the APK
* **[Download Artemis_Resource_Navigator.apk](./Artemis_Resource_Navigator.apk)** *(Click "View raw" or the download icon on the next page to save the file)*

### 2. Installation Steps
1. Download `Artemis_Resource_Navigator.apk` onto your Android device.
2. Open your phone's **Files** or **Downloads** app and tap on the downloaded `.apk` file.
3. If prompted with a security notice, tap **Settings** and enable **Allow from this source** (Install unknown apps) for your browser or file manager.
4. Tap **Install** and wait for the installation to complete.
5. Open **Artemis Resource Navigator** from your home screen or app drawer.
